## 对学习计划的实际影响

1. 第一课入门讲解保留，接着进入真实状态与交互；完整复述可以穿插课堂，不阻塞下一课。
2. 基础标签作为随用随查的语法点，减少脱离实际功能的重复分类题。
3. 第二至第四课以 Vue 现有状态、事件与异步代码为起点，再建立 React 对照。
4. 单独安排 Agent 的事件与任务状态，再进入 Lynx 执行环境和页面实践。
5. Bridge 与原生模块聚焦真实调用边界；Canvas 保留为后续机制与架构专题。
6. 九个主题是当前教学顺序，课次可依据反馈合并、拆分或加深，不把时长当作掌握保证。

## 课堂动态更新规则

每次课程采用“实际场景 → 短代码 / 时序 → 机制解释 → 对照 React / Lynx → 小问题或小修改”的方式。当前不发起独立考试。

- 能独立解释并迁移到新例子：缩短同类复习，转入下一层问题。
- 只记住变量名 / API，但解释不了因果：补机制、执行顺序或状态变化，不整章重学。
- 概念混淆：换一个熟悉场景，明确提示后再判断；保存提示历史。
- 已讲懂但编码卡住：增加局部实现练习，代码产物与口头理解分别记录。
- 反馈不足：记为待确认，按当前代码基线继续讲解，不停下来等待问答摸底。

每次更新记录日期、实际证据、提示情况、仍有问题，以及下节课保留 / 加深 / 跳过的内容。同步修改 [学习路线](README.md) 和 [进度表](progress.md)，历史结论通过追加日志保留。
