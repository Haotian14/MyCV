## 学习优先级

### P0：项目表达、基础和现场编码

这三项作为持续补强主线。当前先从代码讲解开始，相关问题与编码练习穿插课程，未验证项保留为“待确认”，不阻塞继续学习。

| 内容 | 围绕自己的项目练习 | 完成条件 |
| --- | --- | --- |
| 项目真实性与表达 | 问题卡片从 SSE 到用户提交再到 Agent 续跑；明确自己的工作与服务端保证 | 先用 2 分钟概述，再经受 10 分钟异常追问；区分事实与改进设想 |
| Vue / JS / 浏览器基础 | Vue 2.7 与 Vue 3 的机制差异；Promise / 微任务；页面隐藏与恢复；请求取消；Nuxt SSR | 对具体代码预测行为、解释原因，并完成一个小例子 |
| 现场编码与算法 | 事件去重与状态归并、带超时的 Bridge 请求管理、并发限制；数组 / Map / 栈 / 队列 / 遍历与复杂度 | 不依赖 AI 代写，完成实现，主动提出并验证边界 |

特别注意：Composition API 是 API 形式，Vue 2.7 和 Vue 3 底层响应式机制仍有差异；TSX 也不代表使用 React。[Vue 2.7 官方迁移说明](https://v2.vuejs.org/v2/guide/migration-vue-2-7.html)

### P1：Lynx 与 React 的短期补齐

| 顺序 | 学习内容 | 交付证据 |
| --- | --- | --- |
| L1 | WebView、JSBridge、Lynx 引擎、ReactLynx、Native Modules 分别负责什么 | 自己画出两条渲染 / 原生调用链路，口述迁移边界 |
| L2 | React 状态快照、函数更新、Effect 与清理、闭包 | 独立写一个异步交互卡片，说明重复点击和卸载后的处理 |
| L3 | `<view>` / `<text>`、CSS 适配、`bindtap`、滚动与长列表 | 在 Lynx 运行时预览静态卡片；保存版本、平台和运行结果 |
| L4 | ReactLynx 双线程、首屏、副作用、主线程脚本 | 用具体例子解释哪些逻辑放后台线程；说明主线程仍可能被阻塞 |
| L5 | 原生模块与平台适配 | 列出相册 / 文件 / 外跳等接口契约；区分类型声明、Mock 和真正宿主实现 |
| L6 | 小规模迁移验证 | 完成问题卡片的异常回放，并写迁移取舍；真实网络与原生能力分开验收 |

不预设必须先精通整个 React 生态或读完 Lynx 源码。先把一个熟悉的场景做透，再扩展。

## Lynx 入门九节课

当前安排：按首轮 [代码摸底](assessment.md) 调整为以下九个主题；直接继续第二课，提问放在学习过程中。原第一课练习保留，后续可按课堂反馈合并、拆分或加深主题。

每节讲解约 30～45 分钟，编码练习另算；按理解和实践结果调整。每次先阅读自己的项目中一小段相关逻辑，说明它解决的问题，再用个人编写的简化示例对照 ReactLynx。L1～L6 是能力验收项，与课次不是一一对应。

| 课次 | 主题 | 对照实际项目的切入点 |
| --- | --- | --- |
| 1 | 运行环境与基本标签 | 入门讲解已进行，完整复述穿插后续课堂；直接进入第二课 |
| 2 | 从 Vue 状态到 React 状态 | 播放中的音色、本地选择、服务端确认；ref / computed 与状态快照 |
| 3 | 从组件通信到业务分层 | props / emit、provide / inject、composable，再对照 React props / Context / Hooks |
| 4 | 异步、生命周期与竞态 | 试听失败、播放器清理、前后台恢复、过期响应，再进入 React Effect |
| 5 | Agent 事件与任务模型 | SSE 连接、业务任务、用户交互卡的状态；从事件到续跑的完整链路 |
| 6 | ReactLynx 执行环境 | 双线程、首屏、副作用、元素 / 样式 / 滚动与浏览器 API 的边界 |
| 7 | 最小工程与卡片实践 | 先实现个人音色卡片，再用模拟事件驱动问题卡片；记录实际运行范围 |
| 8 | 原生模块与宿主接口 | 用已核对的外跳 / 存储调用理解集成边界；实际能力单独验证 |
| 9 | 一致性、异常恢复与复盘 | 重复提交、回执丢失、重放、快照版本与会话隔离；穿插小型独立实现 |

这九节是 Lynx 入门课；Vue 原理、编码算法、Canvas 与岗位模拟属于后续专项训练。

### P1：巩固与岗位相关的优势

- Agent：传输连接、服务端任务、用户交互卡片分开建模；事件重放、提交回执、快照与实时事件合并、跨项目隔离。
- Canvas：视口与文档坐标、空间索引、命中检测、撤销重做、增量保存冲突；定位 CPU / 绘制 / 内存瓶颈。
- Hybrid：Bridge 请求生命周期、宿主能力协商、App 前后台切换、外跳后的回执补查、媒体缓存与降级。
- 系统设计：把上传、生成、任务恢复、结果落图、持久化串起来，明确每个环节的负责人和失败恢复方式。

### P2：按目标岗位和实践结果扩展

媒体解码与缓存、Canvas2D / WebGL 的适用边界、Worker、包体与启动链路、Lynx 原生集成 / 自定义元素。当前先不把这些全部展开为必修，也不把模型训练作为前端入门前置条件。
